# Home Solutions DE

Responsive login page built for the Masterschool Codio project "Home Solutions DE".

## Live Demo

https://zorropy.github.io/home-solutions-de/

## Stack

- HTML5
- CSS3

## Files

- `index.html` contains the page structure
- `styles.css` contains the layout and responsive styling
- `homes.svg` is the provided logo asset

## Run Locally

Open `index.html` in a browser.

## Notes

The page is implemented as a mobile-first responsive layout and matches the provided Codio reference as closely as possible.
